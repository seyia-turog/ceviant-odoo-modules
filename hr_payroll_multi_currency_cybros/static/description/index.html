HR Payroll Accounting Multi Currency

Overview

Odoo Payroll app moved to Odoo Enterprise in Odoo 13.0 and if you are using Odoo community 16.0 and want to use payroll app, you can download free apps Odoo 16 Payroll and Odoo 16 Payroll Accounting.
This module depend on the above free two modules and enable you to create payslips in any currency used in your company and it will reflect that in accounting journal entry.

Note: This module only working in Odoo Community Edition with the above-mentioned module.

Features
Ability to use any currency in the employee contract.
Ability to create payslip with any currency depend on employee contract.
Accounting journal entry will be created depend on the payslip currency.
Ability to print payslip and payslip details reports with multi currency.
